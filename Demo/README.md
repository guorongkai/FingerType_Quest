# FingerType Quest Demo

This folder contains a standalone demonstration build of FingerType Quest, a child-friendly English typing game for beginning keyboard learners.

## Run it

Open `index.html` in a modern desktop browser. No installation, server, account, or network connection is required.

## Included activities

- **Word Practice** — shows the next letter, target key, and matching finger.
- **Dictation** — speaks the word and gives feedback after each key press.
- An on-screen QWERTY keyboard with animated finger guidance.
- Gentle error feedback: incorrect letters are not added to the word, so learners can simply try again.

The demo keeps its practice content and interface in one HTML file, making it easy to preview or share.

For the full Alpha app, including Markdown word banks, sentence practice, and the Bank Library, see the repository's `main` branch.

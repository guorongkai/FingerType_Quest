# Repository Instructions

## Documentation synchronization (required)

- Every repository change must review and update both `README.md` and `DESIGN.md` in the same task.
- `README.md` must stay accurate for user-visible behavior, setup, operation, privacy, dependencies, and project layout.
- `DESIGN.md` must stay accurate for architecture, UI behavior, data flow, integrations, security boundaries, key functions, and verification results.
- A change is not complete until both documents have been checked and updated, including small fixes and refactors.
- Never copy API keys, secrets, private tokens, or sensitive attached-document content into either document.
